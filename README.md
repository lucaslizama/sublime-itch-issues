# Sublime Itch: issues

Sublime Itch is a desktop app for writing itch.io devlogs in Markdown. It
uploads the images to itch and writes the HTML that itch's editor takes, so
the devlog can be pasted straight into the HTML view.

Get it on itch.io: https://lucaslizama.itch.io/sublime-itch

This repository only holds the issue tracker. The app's source isn't here.

## Reporting a problem

Open a new issue and pick "Bug report". The form asks for the app's version
(shown next to its name at the top of the window, and in About), whether it
runs on Linux or Windows, and what happened. When something fails, the app
usually explains why in the line at the bottom of its window; copying that
line into the report helps a lot.

Ideas and wishes are welcome too, as a "Feature request".

Please leave out anything private. Reports never need an itch.io password,
cookie or token, and screenshots of a devlog can be cropped to the part that
matters.
